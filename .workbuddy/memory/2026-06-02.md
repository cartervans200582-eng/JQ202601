## BD工作动态管理系统 — PWA部署上线

### 技术决策
- 选定方案：GitHub Pages (Public) + jsDelivr CDN + PWA + IndexedDB + AES-GCM加密
- 原始系统：React 19 + TypeScript + TailwindCSS + Vite 8 + PWA
- 原始后端：Express 5 + SQLite (12张表)
- 改造方式：保留前端React代码不变，写新index.html包裹层，用fetch拦截器将/api/*请求全部转向IndexedDB

### 架构
- 数据层：IndexedDB (12个object stores)，AES-GCM加密（PBKDF2密钥派生，200000迭代）
- 安全层：密码登录、5次错误锁定30秒、QR扫码登录（HMAC token，5分钟有效）
- API层：fetch拦截器处理所有后端路由（40+ endpoints）
- 部署：GitHub Pages → jsDelivr CDN（国内免代理访问）
